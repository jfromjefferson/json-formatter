# JSON Formatter

![Repo Size](https://img.shields.io/github/repo-size/jfromjefferson/json-formatter)
![License](https://img.shields.io/github/license/jfromjefferson/json-formatter)

Um formatador de JSON simples, bonito e fácil de usar.

## 💻 Demonstração

Acesse a versão ao vivo aqui:  
🔗 [https://inquisitive-monstera-90414b.netlify.app](https://inquisitive-monstera-90414b.netlify.app)

## ✨ Funcionalidades

- Formata JSON com indentação automática
- Validação de JSON em tempo real
- Interface limpa e responsiva
- Feedback visual em caso de erro de sintaxe

## 🚀 Tecnologias

- TypeScript
- SCSS
- HTML5 + CSS3

## 🛠️ Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/jfromjefferson/json-formatter.git
```

2. Acesse a pasta do projeto:

```bash
cd json-formatter
```

3. Instale as dependências:

```bash
npm install
# ou
yarn install

```

4. Rode o projeto localmente:
```bash
npm run dev
# ou
yarn dev

```
